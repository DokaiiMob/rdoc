    Открытый формат адаптивных офлайн-документов

    Этот файл — эталонная демонстрация Responsive Document (.rdoc): самодостаточный HTML-полиглот с манифестом, встроенными стилями и микро-рантаймом. Его можно открыть двойным кликом в любом браузере — на телефоне, планшете или десктопе.

    Инфо

    Никакого CDN, никаких трекеров, никаких внешних шрифтов. Всё, что нужно для чтения, уже внутри файла.

    Зачем это нужно

    PDF проектировался под печать A4. На смартфоне его приходится зумить и скроллить горизонтально. Веб-страницы адаптивны, но разваливаются без сети.

    .rdoc совмещает лучшее из двух миров:

    Свойство PDF HTML-страница .rdoc
    Автономность Да Часто нет Да
    Reflow на телефоне Нет Да Да
    Офлайн без CDN Да Редко Да
    Печать Отлично Средне Хорошо
    Целостность (hash) Опционально Нет SHA-256

    «Формат файла должен открываться там, где человек уже есть — в браузере — а не требовать ещё одно приложение.»

    Типографика и мера строки

    Основной текст укладывается в комфортную ширину ≈ 65–75 символов. Размер шрифта можно менять кнопками A− / A+ в панели; тема переключается кнопкой Тема.

    Сноски без прыжков

    Классические сноски уводят взгляд в конец страницы. В .rdoc нажатие на маркер открывает popover. Попробуйте нажать сюда: и сюда: .

    Компиляция демо-документа:

    npm install && npm run build

    Минимальный манифест внутри файла:

  "format": "rdoc",
  "version": "1.0.0",
  "title": "Example",
  "contentHash": "sha256-hex..."
}

    Врезка и предупреждение

    Совет

    Отправляйте .rdoc.html себе в Telegram «Избранное» или по AirDrop — на телефоне файл откроется мгновенно, без установки ридера.

    Важно

    Не встраивайте внешние http(s)-картинки: компилятор отклонит их. Используйте локальные файлы — они будут инлайнены в base64.

    Архитектура контейнера

    1. UTF-8 HTML — валидный документ, открывается двойным кликом.
    2. JSON-манифест — application/rdoc+json с метаданными и SHA-256.
    3. Семантический контент — чистый HTML без внешних зависимостей.
    4. Вшитый CSS — светлая/тёмная тема, print, мобильный reflow.
    5. Микро-рантайм — TOC, прогресс, шрифт, сноски, печать в PDF.

    Печать

    Кнопка PDF вызывает системный диалог печати браузера (window.print). Так вы получаете «чистый» PDF без потери исходного адаптивного файла.
