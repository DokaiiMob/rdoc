What ships in the file

  • JSON manifest + SHA-256 contentHash (NFC + LF canonicalization)
  • Strict CSP — no network exfiltration while reading
  • ~4.5 KB reader runtime: TOC, progress, font size, theme, print
  • CLI, OS association, Obsidian export plugin
  • Playground PWA: install from the browser menu for offline convert after first visit
